# Rag4you — site vitrine et 9 réalisations RAG

Site vitrine de services freelance spécialisés en RAG (Retrieval-Augmented Generation), avec neuf réalisations construites de bout en bout sur données publiques. Chaque réalisation traite un type de besoin différent : type de documents, volume, contrainte de confidentialité ou de budget. Le site rejoue des sessions réelles enregistrées : aucun RAG n'y tourne en permanence.

Statut : site vitrine en ligne (version en construction) ; [démo 01](demos/01-assistant-entrepreneurs/) écrite et testée, en attente de déploiement.
